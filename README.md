# Mi Proyecto Web

Este proyecto consiste en una página web estática desarrollada exclusivamente con **HTML5** con el objetivo de practicar el control de versiones con Git, el flujo de trabajo mediante ramas y Pull Requests en GitHub, y la documentación técnica con Markdown.

## Instalación

1. Clona este repositorio en tu equipo local:
   git clone https://github.com/plopezm-rgb/mi-proyecto-web.git
2. Accede a la carpeta del proyecto:
   cd mi-proyecto-web
3. Abre el archivo `index.html` con tu navegador web preferido.

## Estructura del proyecto

- `index.html`: Archivo principal que contiene toda la estructura HTML de la página.
- `.gitignore`: Archivo de configuración para excluir directorios y archivos locales innecesarios (como `.vscode/`).
- `README.md`: Documentación principal del proyecto.

## Mejoras implementadas

- **Menú de navegación (`feature/menu`)**: Se añadió una cabecera con enlaces internos (`#inicio`, `#contacto`) para facilitar la navegación dentro de la página.
- **Formulario de contacto (`feature/formulario`)**: Se incorporó una sección de contacto con campos para nombre, correo electrónico, mensaje y botón de envío.
